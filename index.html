ARDUINO PROJECT NOTE

버튼식 신호등 키트

버튼을 누르면 빨간불에서 노란불을 거쳐 초록불로 바뀌는 아두이노 신호등 프로젝트입니다.

Arduino Uno신호등 키트푸시 버튼D11 · D12 · D13
먼저 모듈의 핀 표기를 확인하세요. 이 문서는 GND / R / Y / G인 4핀 신호등 모듈을 기준으로 작성했습니다. 실제 기판에 5V 핀이 따로 있다면 5핀형이므로, 그 핀은 아두이노 5V에 추가 연결해야 합니다.

1. 동작 순서

전원을 켜면 빨간불로 대기합니다. 버튼을 한 번 누르면 자동으로 아래 순서대로 진행됩니다.

빨강 · 2초→노랑 · 2초→초록 · 유지

2. 준비물

  • 아두이노 Uno 1개
  • 4핀 신호등 모듈 1개
  • 푸시 버튼 1개
  • 점퍼선과 브레드보드
  • USB 케이블

3. 배선 정보

신호등 모듈의 LED와 저항은 모듈에 포함되어 있으므로 별도 LED나 저항을 추가하지 않습니다.

부품모듈 핀아두이노 연결 핀역할
신호등 모듈GNDGND공통 접지
신호등 모듈RD11빨간 LED
신호등 모듈YD12노란 LED
신호등 모듈GD13초록 LED
푸시 버튼한쪽 다리D2버튼 입력
푸시 버튼반대쪽 다리GND공통 접지

4. 아두이노 코드

Arduino IDE에 붙여넣고 보드와 포트를 선택한 뒤 업로드하세요.

const int RED_LED = 11;      // 신호등 모듈 R
const int YELLOW_LED = 12;   // 신호등 모듈 Y
const int GREEN_LED = 13;    // 신호등 모듈 G
const int BUTTON = 2;        // 푸시 버튼

void allOff() {
  digitalWrite(RED_LED, LOW);
  digitalWrite(YELLOW_LED, LOW);
  digitalWrite(GREEN_LED, LOW);
}

void setup() {
  pinMode(RED_LED, OUTPUT);
  pinMode(YELLOW_LED, OUTPUT);
  pinMode(GREEN_LED, OUTPUT);
  pinMode(BUTTON, INPUT_PULLUP);

  // 시작 상태: 빨간불
  allOff();
  digitalWrite(RED_LED, HIGH);
}

void loop() {
  // INPUT_PULLUP: 버튼을 누르면 LOW가 됩니다.
  if (digitalRead(BUTTON) == LOW) {
    delay(30); // 버튼 튐 방지

    if (digitalRead(BUTTON) == LOW) {
      // 빨강 (2초)
      allOff();
      digitalWrite(RED_LED, HIGH);
      delay(2000);

      // 노랑 (2초)
      allOff();
      digitalWrite(YELLOW_LED, HIGH);
      delay(2000);

      // 초록 (계속 켜짐)
      allOff();
      digitalWrite(GREEN_LED, HIGH);

      // 버튼을 뗄 때까지 중복 실행을 막음
      while (digitalRead(BUTTON) == LOW) {
      }
      delay(30);
    }
  }
}

5. 업로드 전 체크

  • Arduino IDE에서 도구 → 보드 → Arduino Uno를 선택합니다.
  • 도구 → 포트에서 연결된 COM 포트를 선택합니다.
  • 버튼은 마주 보는 다리가 아닌, 서로 다른 쪽 다리 두 개를 사용합니다.
  • 버튼 연결은 D2 ↔ 버튼 ↔ GND입니다. 5V에는 연결하지 않습니다.

6. 안 될 때 확인할 점

  • 불이 전혀 안 켜질 때: 모듈의 GND가 아두이노 GND에 연결됐는지 확인합니다.
  • 모듈에 5V 핀이 있을 때: 5핀형입니다. 모듈 5V도 아두이노 5V에 연결합니다.
  • 색이 다르게 켜질 때: R/Y/G 점퍼선이 각각 D11/D12/D13에 맞는지 확인합니다.
  • 버튼 반응이 없을 때: 버튼의 다리 방향과 D2·GND 연결을 확인합니다.
  • 불이 반대로 켜질 때: 모듈 방식에 따라 HIGH와 LOW를 서로 바꿔야 할 수 있습니다.
